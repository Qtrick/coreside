# Consumer information architecture

Primary shell:

1. **Chat** — composer + history
2. **Apps** — sidebar list + app panel (Tool Canvas)
3. **Projects** — sidebar + project pages
4. **Settings** — protected categories + App settings

Settings (Coreside group), ordered:

General → Appearance (theme, dock, wallpapers) → AI Access → Agent → Search & Research → Privacy → Data → Accessibility → Advanced → **Help & learning** → About

**App settings** (added group): preferences created by user apps only.

See [PRODUCT_LANGUAGE_GUIDE.md](./PRODUCT_LANGUAGE_GUIDE.md) and [HELP_AND_LEARNING.md](./HELP_AND_LEARNING.md).
