# Product language guide

Canonical consumer terms for Coreside UI copy:

| Prefer | Avoid in consumer UI |
| --- | --- |
| **Apps** | Tools (sidebar/empty states) |
| **AI connections** / AI Access | Raw provider jargon when unnecessary |
| **Help & learning** | Onboarding admin |
| **Wallpapers** | Backgrounds (settings label) |
| **App settings** | Added Settings (group label for tool-created prefs) |

Internal IDs may keep `toolId`, `tools` table, and Rust symbols. Do not rename protected brand assets.

Product name is exactly **Coreside**.
