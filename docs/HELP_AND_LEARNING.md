# Help & learning

Settings category **Help & learning** (before About) owns:

- **What’s new** (static RC3.4 highlights)
- Restart / continue / reset **Coreside essentials**
- Module list (hides `developerOnly` unless Advanced → developer mode)
- Links to Privacy, Data (backup), and About

Command palette:
- **Start Coreside tour**
- **Open Help & learning**

Search keywords: tutorial, tour, help, shortcuts, privacy, backup, recovery.
